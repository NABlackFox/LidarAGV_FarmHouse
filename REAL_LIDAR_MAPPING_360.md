# Real RPLiDAR 360 Mapping Setup

This document explains how to run real 360-degree mapping using RPLiDAR, RF2O odometry, and slam_toolbox.

## Pipeline

RPLiDAR -> /scan

RF2O -> /odom and TF odom -> base_link

slam_toolbox -> /map

map_saver_cli -> .pgm and .yaml map files

## Required packages

- rplidar_ros
- rf2o_laser_odometry
- slam_toolbox
- nav2_map_server
- rviz2

## Required config files

RF2O config:

src/orlar_agv/config/rf2o_real.yaml

slam_toolbox config:

src/orlar_agv/config/mapper_real.yaml

## TF chain

map -> odom -> base_link -> laser

laser is the LiDAR frame.
base_link is the virtual robot base or LiDAR mount frame.
odom is the odometry frame generated by RF2O.
map is the global map frame generated by slam_toolbox.

## Run order

### Terminal 1: RPLiDAR

cd ~/ros2_archive_ws
source /opt/ros/jazzy/setup.bash
source install/setup.bash

sudo chmod 666 /dev/ttyUSB0
ros2 launch rplidar_ros rplidar_a1_launch.py

### Terminal 2: Static TF

source /opt/ros/jazzy/setup.bash
source ~/ros2_archive_ws/install/setup.bash
source ~/ros2_ws/install/setup.bash

ros2 run tf2_ros static_transform_publisher 0 0 0 0 0 0 base_link laser

### Terminal 3: RF2O Odometry

cd ~/ros2_ws
source /opt/ros/jazzy/setup.bash
source ~/ros2_archive_ws/install/setup.bash
source install/setup.bash

ros2 run rf2o_laser_odometry rf2o_laser_odometry_node --ros-args --params-file ~/ros2_ws/src/orlar_agv/config/rf2o_real.yaml

### Terminal 4: SLAM

cd ~/ros2_ws
source /opt/ros/jazzy/setup.bash
source ~/ros2_archive_ws/install/setup.bash
source install/setup.bash

ros2 launch slam_toolbox online_async_launch.py slam_params_file:=$HOME/ros2_ws/src/orlar_agv/config/mapper_real.yaml use_sim_time:=false

### Terminal 5: RViz

source /opt/ros/jazzy/setup.bash
source ~/ros2_archive_ws/install/setup.bash
source ~/ros2_ws/install/setup.bash

LIBGL_ALWAYS_SOFTWARE=1 ros2 run rviz2 rviz2

RViz settings:

Fixed Frame: map
Map topic: /map
LaserScan topic: /scan
TF: on

## Save map

cd ~/ros2_ws
source /opt/ros/jazzy/setup.bash
source ~/ros2_archive_ws/install/setup.bash
source install/setup.bash

ros2 run nav2_map_server map_saver_cli -f src/orlar_agv/maps/design_and_ai_lab_room -t /map

## Notes

RF2O is used because the real LiDAR setup does not have wheel encoders or physical robot odometry.

RF2O estimates 2D motion from consecutive LaserScan frames and publishes /odom.

slam_toolbox requires /scan, /odom, and /tf to build the map.
